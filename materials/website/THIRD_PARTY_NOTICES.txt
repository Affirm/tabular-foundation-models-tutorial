Iris Dataset
------------

The explorer uses selected UCI Iris records as twelve context rows and three
query examples. Feature measurements remain in centimeters; species names are
encoded as numeric context labels, and query labels are withheld.

Creator: R. A. Fisher
Dataset citation: Fisher, R. (1936). Iris [Dataset]. UCI Machine Learning Repository.
DOI: https://doi.org/10.24432/C56C76
Source: https://archive.ics.uci.edu/dataset/53/iris
